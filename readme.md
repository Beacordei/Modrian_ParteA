# Descrição das decisões tomadas na reprodução

Para reproduzir a obra do Mondrian, utilizei o Illustrator para analisar e medir as proporções, posições dos elementos. Depois, através do p5.js, utilizei as funções rect() e line() para criar os retângulos e as linhas pretas, ajustando as cores e as espessuras, de forma a obter uma reprodução o mais fiel possível do original.
